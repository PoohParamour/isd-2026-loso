### 4.2 หน้าเครื่องมือและไลบรารี (section 3) — 30 วินาที
ชื่อ: **ทั้งระบบใช้เครื่องมือโอเพนซอร์ส ค่า API 0 บาท**

| ชั้น | เครื่องมือ | ใช้ทำอะไร | เวอร์ชัน (ตามไฟล์ในโปรเจกต์) |
|---|---|---|---|
| หน้าเว็บ | Next.js · React · Tailwind CSS | หน้านำเข้า ตรวจแก้ ค้นหา | Next.js 16.3.5 · React 19.2.8 · Tailwind 4 |
| API | FastAPI · Uvicorn · Pydantic · python-multipart | รับไฟล์ ตรวจ บันทึก ค้นหา | 0.141.1 · 0.53.0 · 2.13.5 · 0.0.32 |
| อ่านข้อความ | **Poppler** (`pdftotext`, `pdftoppm`) | ดึงข้อความฝังใน PDF · เรนเดอร์ PDF เป็นภาพ | แพ็กเกจ `poppler-utils` |
| OCR | **Tesseract** (ภาษา `eng`, `tha`) | อ่านตัวอักษรจากภาพ · ฝึกเพิ่มรุ่น `eng_phone` | แพ็กเกจ `tesseract-ocr` + ชุดภาษา |
| ภาพ | **OpenCV** (headless) · **Pillow** · pillow-heif | แก้เรขาคณิต/deskew · ปรับภาพ · อ่านไฟล์ HEIC | 4.12.0.88 · 12.3.0 · 1.1.1 |
| ข้อมูล | **SQLite** (4 ตาราง) | เก็บผลที่ตรวจแล้ว ค้นหา | มากับ Python |
| ตัวแปลงข้อมูล | Python (regex) · ไม่ใช้ LLM | แปลงข้อความเป็น JSON และตรวจกฎ | — |
| รันระบบ | Docker Compose | รันทั้งระบบด้วยคำสั่งเดียว | image `python:3.12-slim`, `node:22-alpine` |

เฉพาะตอนฝึกโมเดล (ไม่ใช้ตอนรันจริง): pdfplumber · pypdfium2 · SIFT + RANSAC (ใน OpenCV) จัดแนว PDF กับภาพเพื่อเตรียมข้อมูลฝึก
**Footnote:** `backend/requirements.txt`, `backend/Dockerfile`, `web/package.json`, `model/tools/photo_training_requirements.txt`
**สคริปต์พูด (≈ 30 วินาที):** ทั้งระบบใช้เครื่องมือโอเพนซอร์ส ค่า API เป็นศูนย์ ฝั่งหน้าเว็บใช้ Next.js กับ Tailwind ฝั่ง API ใช้ FastAPI อ่านข้อความด้วย Poppler และ Tesseract จัดภาพด้วย OpenCV กับ Pillow เก็บข้อมูลใน SQLite และรันทั้งหมดด้วย Docker Compose ส่วนตัวแปลงข้อความเป็นข้อมูลเป็นกฎที่แน่นอน ไม่ใช้โมเดลภาษา
