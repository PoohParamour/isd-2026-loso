Neighborhood processing
The process of moving the center point creates new neighborhoods, one for each pixel in
the input image.
• The two principal terms used to identify this operation are neighborhood
processing and spatial filtering.
• If the computation performed on the pixels of the neighborhoods are linear,
– the operation is called linear spatial filtering (the term spatial convolution also used);
– otherwise, it is called nonlinear spatial filtering.

[PAGE 43]
44
BASIC TERMINOLOGY
(a) 4‐neighborhood;
(b) diagonal neighborhood; 
(c) 8‐neighborhood.

[PAGE 44]

Spatial Filtering
Spatial filtering is a neighborhood processing 
consisting of:
1.
defining a center point, (x, y);
2.
performing an operation that involves only the pixels 
in a predefined neighborhood of the center point;
3.
letting the result of that operation be the 
"response" of the process at that point;
4.
repeating the process for every point in the image.

Median filter
The median filter is a nonlinear filter used in image 
processing. It works by:
• sorting the pixel values within a 
neighborhood,
• finding the median value, and
• replacing the original pixel value with the 
median.

Applications
Neighborhood operations is core concept of commonly used pre-processing techniques from blurring to edge detection, some 
applications are listed below:
Mean Filtering
•Application: Image Smoothing
•Example: Removing noise from a photograph to improve visual aesthetics.
Median Filtering
•Application: Salt-and-pepper Noise Removal
•Example: Cleaning medical images where outliers may represent errors.
Gaussian Filtering
•Application: Blurring for Noise Reduction
•Example: Enhancing fingerprint images by reducing high-frequency noise.
Laplacian Filter
•Application: Edge Detection
•Example: Identifying boundaries between objects in medical imaging.
Sobel and Prewitt Operators
•Application: Gradient-Based Edge Detection
•Example: Highlighting edges in satellite imagery for feature extraction.
